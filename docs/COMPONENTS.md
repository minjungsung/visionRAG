# VisionRAG 컴포넌트별 역할 요약

각 컴포넌트가 시스템에서 수행하는 역할을 정리한 문서.

---

## API & 서비스 레이어

| 컴포넌트 | 역할 |
|----------|------|
| **FastAPI** | HTTP 진입점. 문서 인제스천, 검색, RAG 질의 등 모든 API 엔드포인트 제공 + Prometheus 메트릭 노출 |
| **Celery + Redis** | 대용량 문서 인제스천을 비동기로 처리. Redis가 메시지 브로커, Celery가 워커로 백그라운드 작업 수행 |

## 데이터 & 저장

| 컴포넌트 | 역할 |
|----------|------|
| **Milvus** | 벡터 데이터베이스. 텍스트/이미지 임베딩을 저장하고 ANN(근사 최근접 이웃) 검색 수행 |
| **MinIO** | S3 호환 오브젝트 스토리지. 원본 파일과 추출된 이미지를 저장 |

## 모델 서빙 & AI

| 컴포넌트 | 역할 |
|----------|------|
| **Triton** | GPU에서 여러 모델을 동시 서빙. 배치 최적화 + gRPC로 빠른 추론 |
| **BGE-M3** | 텍스트를 1024차원 벡터로 변환하는 다국어 임베딩 모델 |
| **SigLIP** | 이미지를 1152차원 벡터로 변환 + 텍스트-이미지 정렬 (멀티모달 검색용) |
| **BGE-Reranker** | 초기 검색 결과를 재정렬해서 정확도 향상 (2단계 검색) |
| **Qwen2-VL** | 최종 RAG 답변 생성. 검색된 컨텍스트 기반으로 자연어 응답 생성하는 VLM |

## MLOps & 관측성

| 컴포넌트 | 역할 |
|----------|------|
| **LangSmith** | RAG 파이프라인 트레이싱. 쿼리→검색→생성 전 과정을 추적하고 프롬프트 관리 |
| **ClearML** | 실험 추적. 모델 학습/평가 시 하이퍼파라미터, 메트릭, 아티팩트 기록 |
| **DVC** | 데이터 버저닝. git처럼 학습 데이터와 파이프라인 결과물을 버전 관리 (MinIO를 remote storage로 사용) |
| **Prometheus** | 시계열 메트릭 수집. API 레이턴시, 요청 수, 에러율 등 수치형 지표 저장 |
| **Grafana** | Prometheus 메트릭을 시각화하는 대시보드 |
| **Deepchecks** | 데이터/임베딩 품질 검증. 드리프트 탐지, 분포 이상 체크 |

---

## 데이터 흐름

```
문서 업로드 → MinIO 저장 → unstructured 파싱 → 텍스트/이미지 분리
                                                    │
                         ┌──────────────────────────┼──────────────────┐
                         ▼                                             ▼
                   BGE-M3 임베딩                                 SigLIP 임베딩
                         │                                             │
                         ▼                                             ▼
                   Milvus text_chunks                         Milvus image_chunks
                         │                                             │
                         └──────────────┬──────────────────────────────┘
                                        ▼
쿼리 → 임베딩 → Milvus 검색 → Reranker → 컨텍스트 조합 → Qwen2-VL → 답변
```
