## 예시: 첫 번째 실험 계획

### EXP-001: 프롬프트 변형에 따른 답변 품질 비교 (계획중)

**날짜**: TBD  
**목표**: 프롬프트 형식이 RAG 답변 품질에 미치는 영향 측정  
**가설**: CoT 프롬프트가 단순 프롬프트보다 Faithfulness 높을 것

**설정**:
- 변경 사항: 3가지 프롬프트 템플릿 (단순 / CoT / Few-shot)
- 비교 대상: 현재 단순 프롬프트 (`src/retrieval/rag.py`)
- 데이터셋: golden QA 50쌍 (구축 필요)
- 메트릭: RAGAS (Faithfulness, Relevancy, Context Precision)

**선행 조건**:
- [ ] 프롬프트 템플릿 시스템 구현
- [ ] RAGAS 평가 스크립트 구현
- [ ] Golden dataset 50+ QA 페어 구축
- [ ] LangSmith 프로젝트 설정

## 실험 규칙

1. **한 번에 하나만 바꾸기** — 변수 격리
2. **항상 baseline 포함** — 비교 없는 실험은 의미 없음
3. **재현 가능하게** — 코드 커밋 해시, 데이터 버전(DVC), 설정 기록
4. **실패도 기록** — "안 됐음"도 유용한 정보
5. **N ≥ 3** — 적어도 3회 반복 후 결론 (분산 확인)
