# VisionRAG 소개

VisionRAG는 멀티모달 지식 관리 시스템으로, 텍스트와 이미지를 통합하여 검색하고 AI 답변을 생성합니다.

## 주요 기능

- 텍스트 문서 검색: BGE-M3 임베딩 모델을 활용하여 텍스트 기반 시맨틱 검색을 수행합니다.
- 이미지 검색: SigLIP 모델로 이미지-텍스트 크로스모달 검색을 지원합니다.
- RAG 파이프라인: 검색된 문서를 기반으로 Qwen2-VL 모델이 답변을 생성합니다.
- 리랭킹: BGE-Reranker로 검색 결과의 정확도를 높입니다.

## 아키텍처

시스템은 다음과 같은 구성 요소로 이루어져 있습니다:

1. FastAPI 백엔드: 사용자 요청을 처리하고 검색 파이프라인을 오케스트레이션합니다.
2. Milvus 벡터 데이터베이스: 문서와 이미지의 임베딩 벡터를 저장하고 유사도 검색을 수행합니다.
3. NVIDIA Triton 추론 서버: GPU 기반 모델 서빙으로 고성능 추론을 제공합니다.
4. MinIO 오브젝트 스토리지: 원본 문서와 이미지를 S3 호환 스토리지에 보관합니다.

## 벡터 데이터베이스 활용

Milvus를 벡터 DB로 사용하여 대규모 문서 컬렉션에서 빠른 유사도 검색을 수행합니다.
텍스트 임베딩은 1024차원, 이미지 임베딩은 1152차원으로 저장됩니다.

## 임베딩 모델 최적화

BGE-M3 모델은 다국어를 지원하며, Triton을 통해 배치 추론으로 성능을 최적화합니다.
모델 양자화와 ONNX 변환을 통해 추론 속도를 개선할 수 있습니다.
